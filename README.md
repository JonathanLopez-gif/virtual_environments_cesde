# Análisis de datos

## Requisitos

- Python 3.13
- Git

## Instalación

1. Clonar el repositorio:

   
   git clone https://github.com/JonathanLopez-gif/virtual_environments_cesde.git
   cd virtual_environments_cesde
   

2. Crear el entorno virtual:

   
   py -m venv .venv
   

3. Activarlo en PowerShell:

   
   .\.venv\Scripts\Activate.ps1
   

4. Instalar las dependencias:

   
   python -m pip install -r requirements.txt
